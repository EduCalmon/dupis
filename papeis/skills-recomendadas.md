# Skills de terceiros que o time aproveita

A Dupis **não copia** nenhuma destas skills: cada uma tem autor e licença próprios,
e linkar mantém você sempre na versão atual dos autores. Instale só as que o
projeto usar. As origens foram registradas pelo time que deu origem à Dupis;
confira licença e conteúdo no repositório antes de instalar (leia o código da skill,
como de qualquer dependência).

Para instalar, siga o README de cada repositório (em geral, copiar a pasta da
skill para `.claude/skills/` do projeto ou para `~/.claude/skills/`).

Notas:
- **CC BY-SA 4.0** (Trail of Bits) exige atribuição e compartilhamento pela mesma
  licença se você redistribuir o material. Por isso a Dupis só linka.
- **React Bits** (componentes animados, [reactbits.dev](https://reactbits.dev)) não é
  skill; a licença é MIT + Commons Clause. Use por componente e só com aprovação do líder.
- Skills genéricas trazem exemplos de outra stack ou mercado: onde divergirem do
  projeto, valem `PROJETO.md` e os `INSTRUCOES.md` do papel.
- Nada aqui substitui parecer jurídico ou revisão de especialista humano em
  segurança, privacidade ou regras do setor.
